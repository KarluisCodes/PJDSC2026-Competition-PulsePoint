# PulsePoint — Explainable Disease Early Warning

PJDSC 2026 | Research prototype for climate-sensitive infectious disease early warnings in the Philippines.

## Project objective
Develop and **retrospectively validate** a reproducible framework that uses surveillance,
historical environmental signals, forecast models, and interpretable warning thresholds.
Dengue and leptospirosis are modeled separately. This repository currently covers
**feasibility and data ingestion only**, not a completed forecasting application.

## Data sources
- UPRI–Project NOAH: weekly regional and Quezon City dengue/environment observations.
  https://github.com/UPRI-NOAH/dengue-rainfall-dataset
- Parreño (2024): Philippine disease cases, 2017–2021 (original and imputed series).
  https://doi.org/10.17632/pgwmcfcppk.1
- DOH regional weekly leptospirosis series: **requested/planned, not yet available**.
